Figure 2. Performance profile (Dolan & More style) across all 43 reconciled problem instances. For instance i, f_best(i) is the empirical best final feasible objective found by any method in any run in this study -- 'Best' = empirical best found across all methods/runs in this study; no certified global optimum is available uniformly across the suite. For method m on instance i, the relative error is e_{m,i} = (mean-over-runs final feasible objective - f_best(i)) / (|f_best(i)| + eps); a method that never found a feasible point on instance i is assigned e_{m,i} = +infinity. The curve for method m plots rho_m(tau) = fraction of the 43 instances with e_{m,i} <= tau, as a step function of tau.
