Figure 1. Per-method distribution of min-max normalised final feasible objective values, one panel per benchmark group (TP1-TP9 pooled; SMD problems pooled separately within each of the three (p,q) scales). For instance i, each observed final feasible objective f is normalised as norm(f) = (f - min(S_i)) / (max(S_i) - min(S_i)), where S_i is the set of final feasible objective values from every method and every run on instance i; norm = 0 therefore marks the best value found by any method on that instance, and norm = 1 the worst. Boxes show the pooled distribution (across all instances in the panel's group and all N_RUNS=30 runs) for each method; a method with no feasible final value on a given instance contributes no observation for that instance.
